# LUNAR ROVER PDDL SIMULATION
A project that simulates lunar rovers exploring a planetary surface, capturing data, collecting samples, and interacting with astronauts stationed at lunar landers.

## How to Run
1. Open the files in a PDDL-supported editor (VS Code with PDDL Extension)
2. Right Click on mission1.pddl or mission2.pddl or mission3.pddl and click "PDDL: Run the planner and display the plan"
3. When prompted, click on "BFWS -- FF-parser version"
4. View the generated plan to observe the step-by-step execution of rover and astronaut movements.
